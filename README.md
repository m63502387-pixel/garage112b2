# Гараж 112 — 3D выживание от первого лица (Godot 4.3+)

Мобильный прототип в **альбомной ориентации** (1280×720, растягивается под любой телефон).
Все модели строятся кодом, внешних ассетов нет.
Поменять формат экрана: `project.godot` → `window/size/viewport_width/height` и `window/handheld/orientation` (0/4 — альбом, 1/5 — портрет).

## Запуск
Godot 4.3+ → Import → `project.godot` → F5.
ПК: WASD — ходьба, мышь (зажать ЛКМ на правой половине) — обзор, E — действие, C — свеча, F/Пробел — выстрел.

## Экспорт в APK
Editor → Manage Export Templates → скачать; Editor Settings → Export → Android: SDK и JDK; Project → Export → Add → Android.

## Управление на телефоне
Левая половина — джойстик, правая — свайп-обзор. Кнопки справа: ВЫСТРЕЛ, ДЕЙСТВИЕ, СВЕЧА.

## Сюжет и правила (дотянуть до 06:00)
- По улице бегут люди, за ними зомби. Часть зомби идёт к гаражу и колотит в дверь. Дверь рассчитана на ~120 ударов, врезной замок добавляет +80.
  Если дверь выбита или открыта — зомби заходят внутрь и кусают.
- Врезной замок — на верстаке. Труба — у левой стены. Дрова — из старых ящиков (в одном из них курок).
- Сломанная винтовка висит на правой стене. Нужны затвор (на верхней полке слева) и курок (в ящике). Потом «ДЕЙСТВИЕ» на винтовке — сборка.
- Заряжай банками с солью (белые банки на полках): +4 заряда. Зомби гибнет от двух попаданий солью.
- Калории: огурцы ≈ 0 ккал, варенье 1700 ккал. Огонь — только с трубой. Фары патруля: не стой на улице, не свети дверью, дым из трубы виден.
